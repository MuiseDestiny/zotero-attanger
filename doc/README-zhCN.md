# Zotero Attanger

<p>
  <img src="../addon/chrome/content/icons/favicon.png" width="48" height="48" alt="Attanger 图标">
</p>

Attanger 是 Attachment Manager 的缩写，用于管理 Zotero 附件：附加最近下载的文件、将文件匹配到条目、按照 Zotero 原生模板重命名，以及按规则移动或复制到固定的目录结构。

## 主要功能

- **三种工作模式**：附件留在 Zotero 存储中；移到自己的文件夹并以链接方式使用；或留在 Zotero 中，同时在外部文件夹保留一份按规则整理的副本。
- **原生重命名**：按 Zotero 的文件名格式重命名附件，可选同步附件标题、移除重音符号，并支持正则命名例外。
- **目录结构**：按分类、年份或任意 Zotero 模板变量生成子目录；变量值中的 `/` 可生成多级目录。
- **下载文件夹**：把最新下载的文件附加到条目或分类，或按标题把一批 PDF 匹配到所选条目。
- **自动处理**：通过 Attanger、拖入或 Zotero Connector 新增的附件，会按当前模式自动重命名和整理。
- **编辑后重命名**：标题、作者、年份或 Better BibTeX citation key 变化后，自动同步链接附件的文件名。
- **安全的文件处理**：移动存储附件时保留标注、笔记、标签、关联和全文索引；从不覆盖已有文件。
- **其他**：用其他程序打开附件；常用命令可设置快捷键。

## 安装

1. 从 [Releases 页面](https://github.com/MuiseDestiny/zotero-attanger/releases)下载最新的 `.xpi`。
2. 在 Zotero 中打开**工具 > 插件**（旧版为**工具 > 附加组件**）。
3. 点击齿轮图标，选择**从文件安装插件…**，然后选择下载的 `.xpi`。
4. 如有提示，重启 Zotero。

Attanger 支持 Zotero 7 至 10。

## 快速开始

### 选择工作模式

|                   | 仅 Zotero 存储           | 外部链接             | Zotero 存储 + 外部副本   |
| ----------------- | ------------------------ | -------------------- | ------------------------ |
| Zotero 打开的文件 | 存储文件                 | 链接文件             | 存储文件                 |
| 文件同步          | Zotero 官方存储 / WebDAV | 网盘或其他同步工具   | Zotero 官方存储 / WebDAV |
| 外部目录          | 不需要                   | 必填，文件保存在这里 | 必填，保存单向副本       |
| 适用文库          | 全部                     | 仅可编辑的个人文库   | 全部                     |

- **仅 Zotero 存储**：使用 Zotero 官方存储或 WebDAV 同步，只需要统一的文件名。
- **外部链接**：希望文件放在自己的文件夹中，由坚果云、OneDrive、Dropbox 等工具同步。
- **Zotero 存储 + 外部副本**：既保留 Zotero 文件同步，又想在 Zotero 之外浏览一份整理好的文件夹。

### 上手步骤

1. 打开 Zotero **设置**（Windows 和 Linux 为**编辑 > 设置**，macOS 为 **Zotero > 设置**），选择 **Attanger**。
2. 在**工作模式**中选择模式。外部模式需点击**选择…** 按钮指定文件夹，直到显示**配置完成**。
3. 在**附件命名与目录**中检查文件名规则、子目录和路径示例。
4. 如需使用**附加新文件**或**匹配附件**，在**下载文件夹**中添加下载目录。
5. 先用少量条目试一试，再批量处理。
6. 切换模式不会改动已有附件。需要整理时，选中条目，右键选择 **Attanger > 移动附件**或 **Attanger > 同步外部副本**。

### 工作模式

<p>

</p>

| 模式                       | 行为                                                               | 目录             |
| -------------------------- | ------------------------------------------------------------------ | ---------------- |
| **仅 Zotero 存储**         | 附件保存在 Zotero 中，由 Zotero 文件同步。可按规则重命名。         | 无               |
| **外部链接**               | 附件移到外部目录，Zotero 以链接方式打开。即以前的“链接”附加类型。  | **文件保存目录** |
| **Zotero 存储 + 外部副本** | 附件仍保存在 Zotero 中，并在外部目录自动保留一份按规则整理的副本。 | **副本保存目录** |

**链接选项**（仅外部链接模式）：

- **自动移动新添加的附件到文件保存目录**（默认开启）：新的存储附件会先重命名（如已开启自动重命名），再移入保存目录并转换为链接附件。
- **保留原始文件（移动变为复制）**（默认关闭）：移动链接附件时保留原位置的旧文件，菜单中的“移动”也会变为“复制”。存储附件无论是否开启都会被转换，其存储文件随旧条目一起删除。
- Zotero 不同步链接文件，请用网盘等外部工具同步保存目录。群组文库中的附件不会被转换。

**副本说明**（仅外部副本模式）：

- 副本按子目录和文件名规则放置。重命名附件或调整分类后，副本随之移动并清理旧副本。
- 副本只从 Zotero 单向更新。在 Zotero 之外修改过的副本不会被覆盖；在 Zotero 中删除附件时副本保留。
- PDF 副本不包含在 Zotero 中添加的标注，因为标注保存在 Zotero 数据库中。
- Zotero 文件同步（官方存储或 WebDAV）照常在 Zotero 的同步设置中配置。

**自动删除移动后为空的文件夹**（外部模式，默认关闭）：文件移走后，删除因此变空的文件夹（忽略 `.DS_Store` 和 `Thumbs.db`）。只清理外部目录或下载文件夹内部的子文件夹；这些目录本身和 Zotero 存储目录永远不会被删除。

### 附件命名与目录

<p>
  <img src="images/settings-names-folders.png" width="560" alt="使用自定义子目录模板的附件命名与目录设置">
</p>

- **自动重命名添加的附件**：与 Zotero 自带的自动重命名是同一个开关（`extensions.zotero.autoRenameFiles`），修改后 Zotero 本身也会受影响。
- **文件名规则 > 设置重命名规则…**：打开 Zotero 原生编辑器。Attanger 的所有重命名都使用这里的格式，参见 [Zotero 文件重命名说明](https://www.zotero.org/support/file_renaming)。
- **重命名后同步修改附件标题**（默认关闭）：把附件标题改为新文件名（含扩展名）。即使关闭，标题与旧文件名相同或为通用标题“PDF”时也会同步。
- **子目录**（外部模式）：**按 Zotero 分类**（`{{collection}}`，默认）、**按年份**（`{{year}}`）、**不使用子目录**，或**自定义模板…**。选择自定义模板后会显示**子目录模板**和**将变量中的正斜杠 (/) 解析为子文件夹分隔符**（默认开启）。
- **输出路径示例**（仅 Zotero 存储模式下为**文件名示例**）：以 Wang、2026、“Learning representations”和分类“Machine Learning”为例实时预览，不会修改实际附件；如果示例文件 `paper-2026.pdf` 会被文件类型或命名例外排除，也会直接提示。

子目录模板的解析方式：

- 用 `}}` 与 `{{` 之间的 `/` 分隔各级目录，例如 `{{collection}}/{{year}}`。
- `{{collection}}` 必须单独作为一级，会展开为分类路径，例如 `Machine Learning/Transformers`。手动命令优先使用左侧选中的分类（如果条目属于该分类），否则使用条目的第一个分类；不在任何分类中的条目没有分类目录。
- 其他各级按 Zotero 文件名模板语法、以父条目为准生成，例如 `{{ year }}` 或 `{{ creators max="1" }}`，并移除文件夹名中不允许的字符。开启正斜杠选项时，变量值中的 `/` 会生成下级目录，否则会被移除。

### 下载文件夹

<p>
  <img src="images/settings-download-folder.png" width="560" alt="下载文件夹设置">
</p>

下载文件夹用于**附加新文件**、**匹配附件**和**匹配Attanger附件**；不设置也不影响普通导入。

- **下载文件夹路径**：用**选择…** 设置主文件夹，用**添加文件夹…** 添加更多文件夹，用**移除**删去额外的文件夹。“附加新文件”取所有文件夹中最新的文件，两个匹配命令按顺序依次查找。
- **从 PDF 读取标题**：**永不**、**仅限外文**（默认）或**始终**。决定“匹配附件”用条目标题与 PDF 中读取的标题比较，还是与文件名比较。
- **附加或匹配成功后删除下载文件夹中的源文件**（默认开启）：“附加新文件”或“匹配附件”成功后删除源文件。只有左侧选中**我的文库**或其中的分类时才会删除；“匹配Attanger附件”从不删除文件。

### 自动处理

<p>
  <img src="images/settings-automatic-processing.png" width="560" alt="自动处理设置">
</p>

- **识别独立导入 PDF 的文献信息**（默认开启）：没有父条目的 PDF 先经过 Zotero 的元数据识别，生成父条目后再处理；关闭或识别失败时保持原样。它与 Zotero 自带的**自动检索 PDF 和电子书的元数据**是两个独立设置。
- **条目信息变更时自动重命名已链接附件**（默认关闭）：Zotero 只在添加文件时重命名，之后修改标题、作者、年份或 Better BibTeX citation key，已有链接附件可能仍保留旧文件名。开启后会再次重命名。只处理已存在、可编辑、属于所设类型的链接文件，并遵守“不进行自动移动、复制或重命名”规则。
- **调整编辑后的等待时间**（开启上一项后显示）：
  - **编辑后重命名防抖（毫秒）**（默认开启，1000）：一次编辑可能连续产生多次修改通知，等最后一次修改后再重命名。推荐 1000 毫秒；仍重复可调至 1500–3000 毫秒，追求响应速度可尝试 300–500 毫秒。
  - **编辑后重命名延迟（毫秒）**（默认关闭，0）：防抖结束后再额外等待，适用于异步更新的值，例如 Better BibTeX citation key。建议从 300–1000 毫秒开始，仍读到旧值可增至 1500–3000 毫秒。
- **哪些导入会自动处理？** 新导入的附件（包括 Attanger、拖入和 Connector 导入）按当前模式处理；直接添加的链接附件不会被转换。独立 PDF 仅在自动识别成功并生成父条目后处理。

**文件类型与命名例外**：

- **重命名/移动的附件类型**（默认 `pdf,doc,docx,txt,rtf,djvu,epub`）：用逗号分隔扩展名，不区分大小写，可带或不带前导点；留空表示所有类型。其他类型的文件不会被重命名、移动或复制。
- **移除文件名中的重音符号**（默认关闭）：把最终文件名中的重音字母和连字转换为普通字母，例如 `Müller` 变为 `Muller`；扩展名保持不变。
- 三组正则表达式，多个表达式用逗号分隔，例如 `SI\d+, .+_si`。它们匹配当前文件名（不含扩展名），且不自动锚定，所以 `SI\d+` 也会匹配 `CASI2`。

| 文件名符合规则时…               | 结果                                                                                  |
| ------------------------------- | ------------------------------------------------------------------------------------- |
| “…原文件名会被保留作为前缀”     | 旧文件名保留在前面：`SI1.pdf` 变为 `SI1_Wang - 2026 - Learning representations.pdf`。 |
| “…不进行重命名”                 | 手动和自动都不重命名。                                                                |
| “…不进行自动移动、复制或重命名” | 自动处理和编辑后重命名会跳过；手动命令照常执行。                                      |

由于规则之间用逗号分隔，单条规则不能包含逗号，因此无法使用 `{2,3}` 这类量词。无效的正则会被忽略并写入调试日志。

## 右键菜单

选中条目后右键，打开 **Attanger** 子菜单。其中三项随工作模式变化：

| 菜单项            | 仅 Zotero 存储   | 外部链接             | Zotero 存储 + 外部副本   |
| ----------------- | ---------------- | -------------------- | ------------------------ |
| 重命名并移动/同步 | **重命名附件**   | **重命名并移动附件** | **重命名并同步外部副本** |
| 移动/同步         | 隐藏             | **移动附件**         | **同步外部副本**         |
| 撤销              | **撤销移动附件** | **撤销移动附件**     | **撤销移动附件**         |

外部链接模式开启**保留原始文件**后，显示为**重命名并复制附件**、**复制附件**和**撤销复制附件**。

- **附加新文件**（只选中一个普通条目时显示）：从下载文件夹中附加最新的文件。接受任意文件类型，忽略隐藏文件和子文件夹；没有可用的下载文件夹时会请你选择一个。
- **重命名并移动附件**：先移动，再重命名；如果移动被跳过，就不会重命名。**重命名并同步外部副本**则先重命名，再同步副本。
- **匹配附件**：按标题相似度把下载文件夹中的 PDF 和 CAJ 文件分配给所选条目，见[匹配下载的文件](#匹配下载的文件)。
- **匹配Attanger附件**：查找已经符合 Attanger 路径和文件名规则的文件，见[重新连接已有文献库](#重新连接已有文献库)。
- **重命名附件**：按 Zotero 文件名格式重命名所选内容中的子附件，独立附件会被跳过。
- **移动附件** / **同步外部副本**：把文件移入文件保存目录，或创建并更新外部副本；独立附件也会被处理。
- **撤销移动附件**：对所选链接附件以及所选条目下的链接附件调用 Zotero 的**转换为存储文件**，Zotero 会询问是否**存储后删除原始文件**。

Attanger 子菜单之外还有两个命令：

- **打开方式**（条目菜单，所选内容包含附件时显示）：用 **Zotero**、**System**（系统默认程序）、记住的程序或**选择其它应用**打开文件。右键点击记住的程序可将其删除。选中普通条目时打开其最佳附件。它通过临时切换 Zotero 的 PDF 打开方式实现，因此主要用于 PDF。
- **附加新文件**（分类菜单）：把最新下载的文件作为独立附件添加到该分类，并开始识别元数据。

## 常用工作流

### 附加最新下载的文件

1. 把 PDF 保存到下载文件夹。
2. 选中对应条目，按 `Ctrl + I`（或选择 **Attanger > 附加新文件**）。
3. 文件附加后，按当前模式重命名并移动或复制；如果开启了删除选项，下载的源文件会被删除。

如果想用 PDF 新建条目，可以右键分类并选择**附加新文件**。

### 匹配下载的文件

1. 把 PDF 放进下载文件夹。
2. 只选中文件确实在其中的条目，按 `Ctrl + M`。
3. 每个条目获得剩余文件中标题最相似的一个，每个文件只使用一次。

> **注意**：匹配没有相似度阈值。只要还有剩余文件，每个所选条目都会分到最接近的那一个，即使并不相符。

只考虑下载文件夹第一层中的 `.pdf` 和 `.caj` 文件，标题较短的条目优先匹配。**从 PDF 读取标题**决定与条目标题比较的内容：文件名（**永不**）、PDF 标题（**始终**），或除标题含中日韩汉字的条目外都使用 PDF 标题（**仅限外文**）。PDF 标题取自元数据，缺失时取字号最大的文字；读取超过 30 秒会放弃并改用文件名。

### 重新连接已有文献库

适用于文件已经按 Attanger 的结构整理好的情况，例如重装 Zotero 或更换电脑之后。

1. 确认子目录模板和 Zotero 文件名格式仍能生成现有的路径。
2. 把该文件夹的根目录添加为下载文件夹。
3. 选中条目，选择 **Attanger > 匹配Attanger附件**。

对于**重命名/移动的附件类型**中的每个扩展名，Attanger 依次在各下载文件夹中查找 `<下载文件夹>/<子目录>/<文件名>.<扩展名>`。如果条目已有以该文件名为标题的附件，则跳过。源文件从不删除。

- 在**仅 Zotero 存储**和**外部链接**模式下，文件会在原位置作为链接附件添加，仅适用于“我的文库”。
- 在 **Zotero 存储 + 外部副本**模式下，文件会被导入 Zotero 存储。如果下载文件夹就是副本保存目录，新的外部副本会以 `name_1.ext` 写在原文件旁边。

### 切换模式后整理已有附件

- **改用外部链接**：选中条目并运行**移动附件**。存储附件会变为文件保存目录中的链接文件，并保留标注、笔记、标签、关联和全文索引。
- **改用外部副本**：选中条目并运行一次**同步外部副本**，之后副本会自动更新。
- **改回 Zotero 存储**：先切换到**仅 Zotero 存储**，或关闭自动移动，再选中条目并运行**撤销移动附件**。否则恢复后的附件会被当作新附件，再次被移出去。

### Better BibTeX 更新后重命名文件

如果文件名格式使用了 Better BibTeX citation key，添加文件时 key 可能还没有生成。

1. 开启**条目信息变更时自动重命名已链接附件**。
2. 防抖保持 1000 毫秒。如果文件名仍使用旧 key，开启延迟并从 300–1000 毫秒开始尝试。

这只会重命名链接文件。对于存储附件，请在 key 变化后运行**重命名附件**。

## 自动处理细节

新附件会先收集约一秒，再逐个处理：

1. 跳过 Attanger 自己刚刚创建的链接附件。
2. 如果开启了**识别独立导入 PDF 的文献信息**，独立导入的 PDF 会先识别；没有生成父条目则停止处理。
3. 不支持的文件类型、符合“不进行自动移动、复制或重命名”规则的文件保持不动。
4. 如果开启了**自动重命名添加的附件**，文件会被重命名；直接添加的链接文件也会在原位置重命名。
5. 外部链接模式开启自动移动时，存储附件先重命名，再移动并转换为链接附件。
6. Zotero 存储 + 外部副本模式下，存储附件先重命名，再复制到副本保存目录。

把条目移到回收站或删除会取消其待处理的操作。所有文件操作都在同一个队列中依次执行。

**移动（外部链接）**

- 需要可编辑的个人文库，否则提示“外部链接模式仅支持可编辑的个人文库。”
- 目标路径为 `<文件保存目录>/<子目录>/<文件名>`。文件先复制到临时文件，校验 MD5 后再以不覆盖的方式放到目标位置：名称被占用时依次加 `_1`、`_2` 等后缀；已在目标位置的文件保持不动。
- 链接附件会被重新链接。旧文件会被删除，除非开启了**保留原始文件**、有其他附件使用它、移动期间它被修改过，或它位于 Zotero 存储目录中。
- 存储附件会被替换为新的链接附件：标注（包括回收站中的）、子笔记、标签、关联、附件笔记和全文索引都会转移，随后删除原存储条目及其文件。

**重命名**

- 需要父条目。新文件名为 Zotero 文件名格式加原扩展名。
- 规则按以下顺序生效：跳过规则、前缀规则、移除重音符号。
- 名称被占用时使用 Zotero 的编号方式（`name 2.pdf`）。
- 被多个附件共用的链接文件会复制为新名称后重新链接，其他附件仍使用原文件。
- 重命名失败（例如文件被占用）时最多重试 5 次，每次间隔 3 秒。

**外部副本**

- 只有存储附件才会生成副本；链接附件会被跳过并提示。
- 附件、文件或所属分类变化约一秒后刷新副本。这只针对已经有副本的附件，所以已有附件需要先手动运行一次**同步外部副本**。
- 缺失的副本会重新生成。在 Zotero 之外修改过、或被其他附件链接的副本会报告为冲突并保持原样；其他情况下以原子方式替换副本，并带备份与回滚。
- 目标路径变化时写入新副本（路径被占用时为 `name_1.ext`），旧副本只有在未被修改且无人使用时才会删除。
- 副本记录保存在 Zotero 数据目录下的 `attanger-external-copies.json` 中。

## 从旧版本升级

首次启动时，Attanger 会一次性转换旧设置：

- 旧的**附加类型：链接**且设置了靶路径时，转为**外部链接**；其他情况转为**仅 Zotero 存储**。**Zotero 存储 + 外部副本**是新模式，需要时请手动选择。
- **附加或匹配成功后删除下载文件夹中的源文件**会设为旧选项**保留原始文件**的相反值，下载文件夹的行为与以前一致。
- 在外部链接模式下，自动移动和**保留原始文件**保持原有含义。
- 快捷键和已有附件不会改变。

| 旧设置                                                               | 现在                                                                                                     |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 附加类型：副本 / 链接                                                | **工作模式**                                                                                             |
| 源路径                                                               | **下载文件夹 > 下载文件夹路径**                                                                          |
| 靶路径                                                               | **文件保存目录**（外部链接）或**副本保存目录**（外部副本）                                               |
| 子目录                                                               | **附件命名与目录 > 子目录**                                                                              |
| 自动移动添加的附件                                                   | **链接选项 > 自动移动新添加的附件到文件保存目录**                                                        |
| 保留原始文件，不删除源文件，移动操作变为复制（移动/匹配/附加均生效） | 移动：**保留原始文件（移动变为复制）**；下载文件夹：取反后的**附加或匹配成功后删除下载文件夹中的源文件** |
| 自动检索独立导入 PDF 的元数据，然后重命名/移动附件                   | **识别独立导入 PDF 的文献信息**                                                                          |
| 从PDF读取标题                                                        | **下载文件夹 > 从 PDF 读取标题**                                                                         |
| 其他设置                                                             | **附件命名与目录**、**自动处理**和**快捷键**                                                             |
| 重命名并移动/复制附件快捷键、移动/复制附件快捷键                     | **重命名并移动/同步附件**、**移动/同步附件**                                                             |

## 注意事项与限制

- Zotero 不同步链接文件，请自行同步文件保存目录；建议在**设置 > 高级 > 文件和文件夹 > 已链接附件的根目录**中把它设为根目录，以便在其他电脑上也能找到链接文件。
- 外部链接模式只适用于可编辑的个人文库，群组文库中的附件不会被移动。除外部副本模式外，**匹配Attanger附件**会创建链接附件，因此也只适用于“我的文库”。
- 从不覆盖已有文件：移动和复制时加 `_1`、`_2` 等后缀，重命名时使用 Zotero 的编号方式（`name 2.pdf`）。
- 只有左侧选中**我的文库**或其中的分类时，才会删除下载文件夹中的文件。
- 外部 PDF 副本不包含 Zotero 标注；如需带标注的文件，请使用 Zotero 的**导出 PDF…**。
- 命名例外规则中不能包含逗号。
- 快捷键中的 `Ctrl` 在 macOS 上同样表示 Control 键。
- 只要还有剩余文件，**匹配附件**就会给每个所选条目分配一个文件，请只选中文件确实存在的条目。
- 直接添加的链接文件可以在原位置重命名，但不会被移动。
- 较新的 Zotero 版本可以在条目信息变化时自行重命名文件；在 Zotero 重命名设置中开启**重命名链接的文件**后，也包括链接文件。请在它与 Attanger 的**条目信息变更时自动重命名已链接附件**之间二选一，不要同时开启。

## 欢迎贡献

欢迎提交问题、修复、新功能、测试、文档和翻译。小而集中的 PR 更容易审查，也更安全。

报告问题时，请提供 Zotero 和 Attanger 版本、操作系统、工作模式、相关设置、准确的复现步骤和调试日志（**帮助 > 调试日志**）。发布日志前请删除私人文献信息和本地路径。

参与开发：

```bash
git clone https://github.com/MuiseDestiny/zotero-attanger.git
cd zotero-attanger
npm install
cp scripts/zotero-cmd-template.json scripts/zotero-cmd.json
# 设置 zoteroBinPath 和 profilePath，建议使用单独的 Zotero 测试配置
npm start
```

`npm start` 会启动加载了插件的 Zotero，并在 `src/` 或 `addon/` 下的文件变化时自动重载。

提交 PR 前：

```bash
npm run build                    # 类型检查，并生成 build/zotero-attanger.xpi
npm test
npx eslint src/modules/menu.ts   # 检查你修改过的文件
```

`npm run lint` 会格式化并修复整个仓库；为保持改动集中，建议只对修改过的文件运行 ESLint。
